# Unified Library：本地模板与在线发现

2026-10-09。本地统一入口及 Web Library provider 边界已实施；Cloud 接入、发布草稿和社区能力仍是后续设计。更新 AssetCloud 重接入方案中有关 Library 同步、草稿和发现入口的设计；不表示 Cloud 已接通。

## 已有能力

本地 Component 已支持选区捕获、完整定义/代码/连线保存、版本、只读预览、宿主绑定、原子插入、撤销和来源记录。已进入 Add from Library 搜索、类型筛选、同窗详情和左侧 Components 分组；Assets 的预览与 Apply 仍可使用。

Variant 已是完整单节点模板，使用 `f8component/1`，已进入 Add node 和左侧节点库。仅参数模板叫 Preset。Component 是展开为普通节点的创作模板，尚非封装的 runtime 子图。

Cloud 现有资产、版本、搜索、订阅和 fork API 可作为迁移基础；旧内容合同不能直接插入当前 Studio。点赞、作者关注、新发布合同接入及统一 Library 均需新增或适配。

## 用户入口

保留一个 Add 搜索窗口，通过画布的加号、Tab、右键 Add 打开。普通 Node、Variant 和 Component 共用搜索；快速添加和浏览详情在同一窗口完成。Graph 和 Extension 将来可以被检索，但动作分别是打开为项目和安装，不能伪装成插入节点。

- 默认 All；可筛选 Nodes、Variants、Components，及 Local、Online、My drafts。My drafts 是个人工作视图，不是第三种存储来源。
- 左侧显示搜索结果，右侧按需展开详情。结果包含名称、类型、来源、作者、简述、版本和兼容性；本地匿名模板不编造云端作者身份。
- 详情显示 Markdown 介绍、标签、许可证、版本说明、依赖、暴露端口和复用 GraphView 的静态图预览。浏览不启动服务或执行模板代码。
- 点 Add 或在结果中按 Enter，添加选定的固定版本。没有待解决选项时直接插入；多个宿主、缺失依赖等情况在当前窗口显示必要选项。
- Variant 保持单宿主便捷规则。多节点 Component 逐个解析外部宿主绑定，不把它简化成 Variant 的第一个节点；选中/右键指向的匹配宿主优先，唯一匹配可自动选择，否则让用户选择。保留模板内部相对布局，一次插入一次撤销。
- 左侧库增加 Components 分组；Service/Operator 下的 Variants 保留。完整草稿管理和发布也可从 Assets/Library 工作区进入，共用搜索与详情组件。

关键词检索本地名称、描述和标签；Cloud 在服务端索引名称、描述、标签和作者。在线搜索做输入防抖、取消过期请求和游标分页。Local 结果立即可用，Cloud 加载或失败状态独立显示，不能让网络失败阻塞本地添加。

## 数据归属：直接查询 Cloud，不镜像在线库

| 数据 | 权威来源 | 本地处理 |
| --- | --- | --- |
| 节点定义 | 已安装扩展 catalog | 现有机制 |
| 草稿与本地模板 | Studio 数据库 | 本地保存与版本历史 |
| 在线目录、作者、介绍、统计、关注 | Cloud | 按需查询；允许短期 HTTP 缓存 |
| 已发布版本内容 | Cloud 不可变版本 | 预览/添加时获取并校验，可缓存固定版本 |
| 已插入节点 | 当前项目 | 保存完整内容，独立编辑与运行 |

不把浏览到的在线条目自动导入本地 Assets，不同步整个远端目录，不比较两份可编辑库的差异。可丢弃的下载缓存属于性能优化；草稿和项目不能放在这类缓存里。默认不承诺离线浏览整个在线目录；离线时本地模板和已保存项目可用，未缓存的在线内容明确不可获取。

Studio Server 作为 Cloud 客户端管理认证与内容校验，Web UI 使用统一 Library 接口。Cloud 是在线数据的权威来源，不意味着浏览器必须直接持有长期凭据。

Library 的来源用显式联合类型：installed node、local asset、cloud asset；不将 Cloud UUID 塞进现有 local assetId 字段。在线引用包含 registry identity、asset ID、固定版本及内容 hash，避免跨 registry 冲突。详情与内容分别读取，不为每条搜索结果下载完整图。

Cloud 详情中的 currentVersion 在用户开始预览/添加时解析并固定。后续下载按该版本和 hash 校验；发布者此时发布新版本不会改变用户正在添加的内容。获取、合同校验、依赖检查通过后，复用 Server 的同一套组件插入事务。失败不得留下半个组件。

现有插入 API 以本地 assetId 为入口，需拆出可复用的“已校验固定模板插入”服务，并增加显式来源解析。项目来源记录需容纳 Cloud 引用；不能为了复用旧 API 而把每个下载项变成用户可编辑的本地资产。

本地与在线独立分页，合并显示时使用明确来源分组，不虚构可比较的跨源热度分数。草稿与它的已发布资产通过显式来源关系展示；不按名称猜测或自动合并。

## 作者草稿与发布

草稿可以是全新作品，也可以由一个明确的在线版本创建；保存 base publication 引用及版本。保存草稿只写本地，用户点 Publish 才产生云端发布。

发布内容经既有清理规则生成 `f8publication/1`，保留定义默认值与示例，清理不允许共享的实例值。编辑 revision、草稿历史和发布版本互不替代。

作者更新自己的资产时提交 expected published version、内容 hash 和幂等请求 ID。云端已变更则提示冲突，允许查看差异或另存作品，不自动双向合并。相同规范化内容不新增内容版本。来源关联在发布成功后落库，网络重试不能产生重复版本；仅修改介绍等元数据走元数据接口。

编辑别人的在线作品创建自己的本地草稿，保留来源与许可；发布派生作品使用新的资产身份，并由 Cloud 验证相应权限和许可要求。本地草稿备份另属项目/工作区备份问题，不引入隐式云同步。

## 社区操作与更新

- Like / Unlike：点赞与取消点赞，第一版不将 Unlike 定义为点踩。
- Follow author / Unfollow：关注作者，获得作品动态。
- Follow asset / Unfollow：关注资产的新发布；展示“关注更新”，不暗示自动安装、下载或替换。
- Library 的 Following 视图按需查询 Cloud。账号操作由 Cloud 校验并持久化，离线时显示不可用，不提前显示已成功。

这三种关系独立、操作幂等。旧 subscribe 可评估迁移为资产关注，不能自动解释为作者关注或点赞。云端控制访问权限和计数；客户端不把本地点击次数当作统计。

已插入项目保持固定来源版本；有新版可以提示并查看说明/预览，再添加新版或创建更新后的草稿。第一版不提供已修改节点与新版模板的自动合并，不替换运行中的图。关注、点赞和浏览不触发图部署或发布。

## 实施顺序及验收

1. **本地统一入口**：Component 加入 Add 搜索、左侧 Components 分组与详情；复用多宿主插入。验收单/多节点、内部连线、宿主歧义、插入位置、失败回滚、一次撤销和离线使用。
2. **Library 来源边界**：静态类型、local/cloud 引用、独立分页/错误状态、固定内容解析。Cloud 未配置时仅显示可用来源，不提供无效社交按钮；用测试 provider 验证契约，不向用户展示假云内容。
3. **Cloud 接入**：迁移当前内容合同、登录、在线搜索/详情、固定版本下载校验、本地草稿与显式发布。验收分页、过期响应、断网、并发发布、幂等重试、权限和旧在线内容不可直接插入的诊断。
4. **社区能力**：点赞、作者/资产关注、动态视图。验收取消操作、重复请求和账户切换后的关系状态。

首轮目标是完成本地添加体验并固定 Cloud 接口边界；在线目录、账号和社区功能在 Cloud 阶段接通。

## 首轮实现边界

`f8studio_web/src/library` 提供显式 local/cloud 固定版本引用、LibraryProvider、现有本地 HTTP 的适配、模板详情/添加及在线搜索状态。产品只配置本地 provider。在线 provider 的测试替身验证防抖、游标分页、重复项去重、过期响应取消、断网及固定 hash 引用传给插入 provider，不向用户展示测试内容。

实际 Cloud 的内容解析、hash 校验和来源记录仍须在 Studio Server 实施。当前 Server 插入仍使用本地 assetId/version，未宣称已支持远端引用。未来 Cloud adapter 必须调用专用服务端解析入口；不能把远端 ID 传给本地资产 API。

Component 保存支持介绍和标签。统一添加复用既有事务、来源记录及撤销；增加可选外部宿主分组平移 `hostOffsets`，不改变可移植 component 内容合同，旧调用省略该参数时行为保持兼容。Component 的 builtin Studio 外部绑定与 Variant 一样按需创建/复用唯一宿主。

保存 Component 的 HTTP 接口现在发送本地 `asset.created` 事件，库在保存后立即刷新。验收通过：230 个前端测试、106 个核心/相关服务端测试、3 个桌面浏览器流程、Python 严格类型检查、TypeScript/生产构建和生成合同一致性检查。浏览器覆盖保存选区与介绍/标签、无需刷新检索、图预览、分别选择两个宿主、保留内部连线、一次撤销，以及 Variant/离线配置回归。这些测试不代表 Cloud 集成或移动端验收已完成。
